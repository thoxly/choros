## Что проверено адверсариально

### 1. РЕГРЕСС-ЛОВУШКА `has_tag_close()` — синтетик-атака (не крашится/не зацикливается)
Юнит-пробы + полный `classify_added_lines` на легальном JSX:
- `onClick={() => foo(a > b)}` (стрелка + сравнение) — не крашит; **но** возвращает CLOSES
  (bare `>` из `a > b` переживает срезку `=>`/`>=`) → это ЗАЯВЛЕННАЯ известная граница (комм. стр.62–65).
- generic `<Component<T>>`, self-closing `/>`, attr-строка `title=">"`, фрагмент `<>` — все
  корректно CLOSES, без краша/зацикливания. `=>`-только и `>=`-только → OPEN (верно).
- Финитный `while read` на finite stdin — зациклиться структурно не может (проверено).

**Вывод п.1: не крашится, не зацикливается, преждевременно тег не рвёт НА ГАРАНТИРУЕМЫХ формах.**
Bare-`>` — единственная дыра, и она документирована (см. N-1).

### 2. Пропуск настоящего фейка / регресс одностроки
- Многостроковый фейк (aria-disabled + inert onClick на РАЗНЫХ строках, причины нет нигде) → **FLAG** ✓
- Многостроковый aria-disabled-only без причины → **FLAG** ✓
- Одностроковый inert (старое поведение) → **FLAG** ✓ (line-local случай НЕ регрессировал)
- sr-only + inert (даже с describedby) → **HARD FLAG** ✓

### 3. Ложняк честной кнопки (ядро задачи)
- `aria-describedby=`/`title=`/`className~stub` на строке ПОСЛЕ `aria-disabled` но ДО `>` → **не шумит** ✓
- Реальные формы из репо подтверждены чистыми: shell.jsx «+ Исполнитель» (631), shell.jsx
  «Экспорт прав» (656), ra-grant-trail.jsx «Экспорт» (423) — все имеют reason-маркер ВНУТРИ
  открывающего тега → block-scope их вычищает (старый line-local ложнил на них).

### 4. Self-test честный (не тавтологичен)
Прогнал НОВЫЕ фикстуры через СТАРЫЙ (line-local, dev) классификатор:
- Ассерт «flag multiline РегрессФейк» (`inert…\t.*РегрессФейк`) **ПАДАЕТ** под line-local
  (флагается голая строка `aria-disabled="true"`, метки «РегрессФейк» в ней нет) → self-test
  exit 2 при реверте. **Non-tautological подтверждён.**
- НО: два honest-ассерта (ЧестнаяДискрайб/ЧестнаяТайтл) кросс-режимно СЛАБЫ — проходят даже под
  line-local (метка не на голой attr-строке, которую ловит line-local). См. N-3 (nit).

### 5. Whole-tree аудит — СОШЁЛСЯ с заявкой строителя
Реконструирован (68 in-scope файлов web/src/screens+app-shell, все строки как '+', per-file `+++`):
- **6 инертных контролов** в скоупе (literal `aria-disabled="true"`; process-editor
  `{!canUndo||undefined}` — динамический, верно НЕ инертный; navigation-onClick с доп.стейтментами
  — верно НЕ inert-idiom). **0 настоящих фейк-кнопок.**
- NEW block-scope: **3 находки** — все `<button…aria-disabled="true">` AccountMenu (shell.jsx
  917/930/978). OLD line-local: **7 находок**. Дельта **7→3 = 4 старых ложняка-строки ушли**,
  3 остались. Точно совпадает с «6 контролов / 0 фейков / старые 4 ушли / 3 нового класса».
- 3 остаточных — ЧЕСТНЫЕ контролы: видимый бейдж «скоро» + sibling `<span class=chs-account-menu__reason>`
  ПОСЛЕ закрытия тега; гейт судит только открывающий тег → причину-соседа не видит. См. N-2.

### 6. Границы (boundary-reset = false negative by design)
«Тихо отброшен» на границе хунка — приемлемо: настоящий НОВЫЙ фейк = смежные '+' строки в ОДНОМ
хунке (внутри тега нет unchanged-контекста → границу не пересечь). Straddle требует '+'-открытие
тега при `>` в позднем хунке с interleaved-контекстом — при смежных вставках недостижимо. Риск≈0
для informational-гейта. См. N-4 (informational).

файлов нет — скоуп даже уже заявленного). Реальный diff-mode на ветке: 0 находок (--required тоже exit 0).

### 8. Флип в required — НЕ флипать (согласен)
3 живых AccountMenu-ложняка + bare-`>` двусторонняя дыра → при required = ложные блоки честных дифов.

## Findings (все NON-BLOCKING)

- **N-1 (nit):** bare-`>` в `has_tag_close` — двусторонняя эвристик-дыра. FN: многостроковый фейк с
  `{x > 5}` ТЕКСТУАЛЬНО перед inert-маркерами преждевременно «закрывается» и пропускается
  (empirically confirmed). FP: честный контрол с bare-`>` перед своей причиной — ложнится. Документировано
  строителем; ни один охраняемый контрол этой формы не использует. Усиливает «не флипать».
- **N-2 (nit):** 3 живых AccountMenu-ложняка (shell.jsx 917/930/978) — reason в sibling `<span>`/бейдже
  ВНЕ открывающего тега; фундаментальный предел «судим только открывающий тег». Fix: aria-describedby на
  кнопку → на reason-span, ИЛИ расширить гейт на тело/следующего sibling.
- **N-3 (nit):** honest-ассерты self-test (ЧестнаяДискрайб/ЧестнаяТайтл) кросс-режимно слабы (проходят под
  line-local). Overall self-test всё равно non-tautological (РегрессФейк ломается). Реальная защита от
  регресса ложняков = whole-tree аудит, не эти ассерты.
- **N-4 (informational):** boundary-reset silent-drop = FN by design; риск≈0 при смежных вставках.
  Приемлемо для informational.

## Блокеров нет
Не крашит/не зацикливает на легальном JSX; старую одностроку не регрессировал; многостроку ловит;
self-test не тавтологичен; whole-tree сошёлся. Гейт корректен в заявленных границах.
