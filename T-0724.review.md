## 1. БОТ ≤ ЧЕЛОВЕК — доказано структурно, не декларативно

`fetchRegistryListCandidates` (`src/http/assistant.ts:449`) вызывает `listRegistryDefs(pool, tenantId, null)` — **ту же функцию**, что `GET /api/registry-defs` (`src/http/registry-defs.ts:1013`) отдаёт человеческому пикеру. Проверил обе стороны:

- Человек: `web/src/screens/screen-processes.jsx:324` — `BindProcessModal` дёргает `fetch(`/api/registry-defs?application_id=...`)`.
- Бот: та же `listRegistryDefs`, тот же `withTenantTx` RLS, **никакого второго SQL-запроса**.

`listRegistryDefs` (registry-defs.ts:848-873) имеет ровно ОДНУ границу — `WHERE tenant_id = $1 [AND application_id = $2]`. Per-registry ACL не существует **ни у человека, ни у бота** — значит паритет достигается не «бот стал уже», а «оба одинаково широки внутри тенанта». Это структурно исключает асимметрию: не может появиться реестр, который видит бот, но не видит человек, потому что источник данных буквально один и тот же вызов.

**applicationId-аргумент не может РАСШИРИТЬ область** — он только фильтрует УЖЕ тенант-скоупнутый массив `registryListCandidates` в памяти (`processToolCall`, `list_registries` case). Даже если модель подсунет `applicationId` чужого тенанта, отфильтрованный список пуст — исходный массив физически не содержит чужих строк. Проверил код (`src/core/assistant-configurator.ts:958-980`) — фильтр `registryListCandidates.filter((r) => r.applicationId === rawApplicationId)`, никакого нового запроса на этом шаге.

## 3. Контур прав агент∩пользователь — гейт наследуется, не обойден

`hasAuthoringDraftGrant(ctx)` (assistant-configurator.ts:695) стоит **ДО** `runConfiguratorLoop` в обоих входах (`handleConfigurator`, `runConfigurator`) — весь тул-луп, включая новый `list_registries`, недостижим без него. Гейт = owner-short-circuit ИЛИ `canOperateSystemAgent(ctx.intersectionGrants)`, где `intersectionGrants` = `makeIntersectionGrantSource(agent, user, ...)` (agent∩user, никогда шире) — этот механизм не тронут этой задачей (T-0475/T-0607), `list_registries` его унаследовал бесплатно, как и заявлено.
