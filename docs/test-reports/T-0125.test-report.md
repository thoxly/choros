## 4. Review findings

Review contract `docs/design/T-0125.review.contract.json`: **verdict=approved** (iter-2), 3 findings:

- **R-1 (blocking, iter-1):** Инстанс-адресация через несуществующий ResourceType → terminate коллапсирует в record-transition-грант (эскалация привилегии при разморозке). Закрыт DESIGN-fix коммитом 2100226: §2.2.1 явно объявляет process_instance dormant-аддитивом; ветвь (б) корректно отвергнута; B-8 двойное условие разморозки; FF-CA-10 поведенческий deny.
- **R-2 (nit, iter-1):** Амортизация record-fetch в batch-PDP не зафиксирована. Закрыт нотой §5 коммитом 2100226: batch = K grant-резолвов над одним target, record-fetch один раз на target.
- **R-3 (nit, iter-2):** Механизм дизъюнктности мис-атрибутирован как «resourceType-match в covering» (которого нет); B-8 surface неполна (не названы ResourceRef-kind + refToScope/NodeLevel); FF-CA-10 не покрывал broad-scope-пробу. Закрыт коммитом 712c3c2: §2.2.1/§2.3/§6 переформулированы на scope-containment (isNarrowerOrEqual); B-8 в §7/§9 дополнен ResourceRef-kind (object-handle.ts:40) + refToScope/NodeLevel (grant-resolver.ts:178, grant-lattice.ts:19); FF-CA-10 дополнен broad-scope-пробой (2 кейса вместо 1).

Все finding'и закрыты до TEST; gate: **PASS**.
