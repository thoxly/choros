## Архитектурные наблюдения (tester perspective)

**Equality-only oracle:** RESOURCE_ORACLE `isDescendantOrSelf(h, a, b) = (a === b)` —
day-1 fail-safe выбор. Широкие узловые гранты (parent-uuid) не покроют child-app.
Полная иерархическая traversal отложена на T-0053 (Stage-2 кандидат).

**page-first порядок:** страница загружается до PDP-gate для получения app_id.
404/403 oracle: несуществующая страница → 404 независимо от наличия гранта у актора.
Существующая страница + нет гранта → 403. Раскрытие подтверждено; UUID v4 entropy
(122 бит) делает перебор нецелесообразным. Cross-tenant RLS полностью блокирует
межтенантный доступ.
