## Деструктив = owner-only day-1 (ADR-нота)

ADR T-0121 §6: деструктив-force (`mgmt_object:schema_destructive`/`apply`) — admin-only.
По умолчанию (fresh DB + seed 026) только genesis-owner проходит через `isGenesisOwner`
short-circuit. Делегирование `apply`-гранта другим акторам возможно через grant API,
но только когда genesis-owner сам выдаст грант через `validateAdminDelegation`.
Это осознанный day-1 дизайн, явно описанный в ADR. R-N1 закрыт live-тестом, подтверждающим
что delegated-grant путь технически рабочий.
