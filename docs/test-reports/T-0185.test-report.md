## Bug closure (T-0087)

Root cause: `tier_published_locked` BEFORE DELETE trigger returned `NEW` (which is NULL for DELETE operations), causing Postgres to silently suppress all deletes without raising any exception. Fix: `RETURN OLD` for draft rows (allows delete), `RAISE EXCEPTION` for published without GUC, `RETURN OLD` for published with promoting GUC.
