## Детальная верификация изменений

### AC-1: grep exec = 0 в web/src/screens/rights/

```
grep '"exec"' web/src/screens/rights/ -r → 0 hits
```

Все 12 вхождений `"exec"` как Operation заменены на `"invoke"` в:
- `ra-data.jsx` (OP_LABEL, OP_RU, axesFromGrants ×2, TRAIL ×4)
- `ra-role-editor.jsx` (INITIAL_GRANTS, ALL_OPS, mapOp ветка удалена)
- `ra-criticality.jsx` (SCENARIOS detail)

### AC-2: axesFromGrants корректность

```js
// ra-data.jsx:205-206
if (r.guarded && (g.ops.includes("invoke") || g.ops.includes("approve"))) axes.guarded = true;
if (r.external && g.ops.includes("invoke")) axes.external = true;
```

Соответствует Operation union в `grant-lattice.ts`. `"exec"` не входит в union —
старый путь был deadcode, теперь корректно на `"invoke"`.

### AC-3: CSS-покрытие invoke (R-1 fix)

```css
/* rights-admin.css:185 */
.chs-opbtn--on.chs-opbtn--invoke { color: var(--chs-color-danger);  background: var(--chs-color-danger-soft);  border-color: transparent; }

/* app.css:533-534 */
.chs-op--exec   { color: var(--chs-color-danger);  background: var(--chs-color-danger-soft); }
.chs-op--invoke { color: var(--chs-color-danger);  background: var(--chs-color-danger-soft); }
```

`--exec` сохранён в `app.css` (OpChip) для обратной совместимости с бэкендом:
`src/http/rights.ts` ещё отдаёт строку `"exec"`. Синхронизация бэкенда —
кандидат-задача отдельно (вне скоупа T-0194).

### mapOp: ветка "exec" удалена корректно

```js
// ra-role-editor.jsx — до T-0194
function mapOp(op) {
  if (op === "write") return "update";
  if (op === "exec") return "invoke";  // ← удалено
  return op;
}
```

`ALL_OPS` теперь не содержит `"exec"`, путь `mapOp("exec")` из `handleSubmit`
недостижим через UI. `mapOp("invoke") → "invoke"` (fallthrough) — корректно.
