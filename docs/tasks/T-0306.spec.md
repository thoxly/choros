Новый тенант должен стартовать **ЧИСТЫМ** (0 мок/демо-данных) и показывать внятный
first-run онбординг с подсказкой «создай первое приложение».

**r1 (отклонено судьёй):** ветка стояла на стало́й базе fed0b962 (июнь); построенный
FirstRunPanel дублировал уже смерженный на dev **T-0598 FirstStepsStrip** («Первые
шаги → Создайте приложение» на том же экране «Обзор»). **r2 (эта ревизия):** ветка
пересажена на свежий dev; FirstRunPanel убран; уникальная ценность T-0306
консолидирована В канонический онбординг-слой T-0598 (один слой, не два).

## 1. РАЗВЕДКА — что реально происходит (проверено на dev@3256f627)

### 1.1 Provisioning-путь тенанта
Единственный путь создания тенанта из UI — `src/core/register.ts::registerTenant`
(HTTP `src/http/register.ts`, экран `web/src/screens/screen-register.jsx`).
После `201` → PKCE → вход → `/` → `/overview`.

`registerTenant` (на dev дополнен T-0574/T-0570/T-0666/T-0633 против июньской
версии) сеет ТОЛЬКО управляющий каркас: tenant, owner-employee, assistant-agent
employee + **agent_card** (T-0574), роли (tenant-owner / role-configurator /
role-constructor-admin / process_designer T-0666), role_assignments, гранты
(authoring_draft, capability, delegable mgmt_object, default-READ T-0570).
**НИ ОДНОЙ строки контент-плоскости** (application/registry_def/record/процессы/
формы/DMN/секции/представления) не сеется — проверено по всем INSERT'ам файла.

Демо/мок-сид (ТЭЛ, core-registries, engine_process_name) — миграции
076..090, 132 с литеральным Dev-Silo `a0000000-…-0001`; RLS не пускает их в
свежий рандомный tenant_id.

### 1.2 First-run UX (закрыто T-0598, дефект — в деградации)
`/overview` уже несёт полосу «Первые шаги» (FirstStepsStrip): «Создайте
приложение» (+CTA), «Подключите LLM-ключ», «Спросите ассистента», опционально
«Настройте права». Полоса скрывается, когда шаги 1-3 подтверждённо пройдены.
Пустота БЕЗ подсказок из формулировки задачи — уже неактуальна.

**Оставшийся дефект (дифф T-0306):** при сбое сигнала (сеть/HTTP/парсинг →
signal===null) шаг рендерился как ПУСТОЙ todo-круг — неотличимо от «не сделано».
Для шага 1 это прямое нарушение принципа first-run: «apps-фетч упал» показывался
так же, как «приложений 0». Пусто ≠ недоступно (principles.md §6).
