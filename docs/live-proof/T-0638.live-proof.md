## FINDING (P2, косметика/UX — НЕ блокер T-0638, для отдельной задачи)

**Разрешённая defer-карточка НЕ исчезает из инбокса.** После `agent.defer_resolved` + завершения инстанса карточка `888ed930` всё ещё в `GET /api/inbox` (27 items). Причина: `src/db/deferred-inbox-store.ts::listDeferredInboxTasks` читает `WHERE type='agent.deferred'` и НЕ вычитает строки, у которых есть последующее `agent.defer_resolved`; inbox-merge (`src/http/inbox.ts` ~780-863) фильтрует defer-строки только по `claimStateMap`, не по resolved-событию. Рекомендация: в `listDeferredInboxTasks` (или в merge) исключать defer-строки, у которых есть `agent.defer_resolved` с тем же `inbox_task_id`/`instance_id` (аддитивно, без новой таблицы — событие уже пишется).
