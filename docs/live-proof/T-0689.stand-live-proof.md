## FRICTION

- **Рядовой (создатель DRAFT-приложения) НЕ может удалить своё приложение из UI/API.**
  `DELETE /api/applications/:id` → 403 FORBIDDEN «not permitted to delete this
  application» для e-orlov, хотя приложение — его личная песочница-черновик.
  `assertMayDeleteConfig` требует owner/admin. Уборку тестового приложения
  пришлось делать вручную в БД (cascade: registry_schema_history → registry_def →
  application). Не блокер T-0689, но противоречит модели «черновик = личная
  песочница автора»: автор может создать, но не удалить.
- В режиме «Изменить» ключ показывается как редактируемое текстовое поле
  (с persisted-значением), а в режиме создания — как «ключ: X · изменить»
  превью-строка. Расхождение косметическое и согласуется с fix (keyTouched/
  subKeyTouched → показать persisted-ключ), но два разных представления одного
  и того же примитива могут путать.
