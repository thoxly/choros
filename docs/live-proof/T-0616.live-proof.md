## Перекрёстная SQL-проверка (диагностика, НЕ замена UI-взгляда)

```sql
SELECT payload->>'proc_key' AS proc_key, count(*)
FROM choros.audit_event WHERE payload ? 'proc_key' GROUP BY 1 ORDER BY 1;
```
```
     proc_key      | count
-------------------+-------
                   |     6   <- task.claimed события, transition_payload.process_key=""
                   |         (НЕ process.started; не фидит инстанс-проекцию — см. ниже)
 acceptance-demo   |     5
 novyy-protsess-10 |     7
 novyy-protsess-2  |    12
 novyy-protsess-4  |    33
 novyy-protsess-5  |    11
 novyy-protsess-6  |    17
 novyy-protsess-8  |     6
 novyy-protsess-9  |     9
 purchaseApproval  |    48
 telLinear         |   109
```

Проверил все 6 "пустых" строк вручную (`SELECT ... WHERE payload->>'proc_key'=''`) — все
6 это `task.claimed`-события верхнего уровня (`role`, `task_id`, `transition_payload.
process_key=""` — вложенное поле другой природы, не `payload.proc_key` на верхнем уровне,
которое читает `resolveDefinitionNames`/`listInstanceProjections`), не относятся к
`process.started` пути и не всплывают в списке инстансов процессов вообще (подтверждено:
ни в UI, ни при подсчёте эти task-claim-события не соответствуют ни одной видимой строке
таблицы инстансов — они из configurator/edit_jsonschema-потока ассистента, не из
запусков процессов).

```sql
SELECT process_key, name, tenant_id FROM choros.process_definition ORDER BY process_key;
```
Результат (29 строк для всех тенантов): **ни одна строка НЕ содержит имя «Канонический
линейный ТЭЛ»** — каждый `process_key` (acceptance-demo, demo-modeler-085, novyy-protsess,
novyy-protsess-2..10, probe-proc, purchaseApproval) резолвится в своё честное
`name` (Приёмка демо / Demo modeler / Новый процесс / Probe / Согласование закупки).
Примечательно: `telLinear` САМ отсутствует как строка в `process_definition` для тенанта
Dev Silo — то есть для инстансов telLinear имя резолвится через ДВИЖОК/другой путь
(«Источник: Движок» в UI), не через `process_definition`, и там честно показано именно
«telLinear» (ключ-эхо), а не «Канонический линейный ТЭЛ».
