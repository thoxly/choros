Функция обновлена корректно:

```js
// ra-data.jsx:208-209
if (r.guarded && (g.ops.includes("invoke") || g.ops.includes("approve"))) axes.guarded = true;
```

Проба node-inline:

## 3. ALL_OPS: состав и CSS-покрытие

`ALL_OPS = ["read", "write", "invoke", "approve"]` — корректная замена
`["read", "write", "exec", "approve"]`. Состав соответствует Operation union в той
части, которую покрывает UI-редактор (остальные: create, delete, transition — были
и до T-0194 вне ALL_OPS, это pre-existing, не регрессия).

**Blocking R-1**: `rights-admin.css:185` содержит:

```css
.chs-opbtn--on.chs-opbtn--exec  { color: …danger…; … }
```

Правило для `--invoke` **отсутствует**. `ra-role-editor.jsx:137` генерирует кнопку
с `chs-opbtn chs-opbtn--invoke`. Когда оп выбрана, к ней добавляется `chs-opbtn--on`,
но `.chs-opbtn--on.chs-opbtn--invoke` не определён — кнопка не получает цветовой
подсветки выбранного состояния. Визуально: "invoke" выглядит невыбранной даже когда
в `g.ops`. Это прямое следствие переименования без обновления CSS.

**Nit R-N2**: `app.css:533` содержит `.chs-op--exec` (стиль для `OpChip`) без
парного `.chs-op--invoke`. Пока `src/http/rights.ts` возвращает `"exec"`, `OpChip`
рендерится с правильным CSS. Если/когда backend обновится на "invoke", чипы в
экране прав потеряют цвет. Масштаб: нит, но стоит закрыть в этом же PR.

**Nit R-N3**: `screen-rights.jsx:198` — пользовательский текст:
```
↳ из грантов с операцией read / write / exec
```
Должно быть: `read / write / invoke`.

**Nit R-N4**: `components.jsx:171` — комментарий:
```js
/* OpKbd — операция гранта (read/write/exec) — машинный «scope»-чип */
```
Должно быть: `(read/write/invoke)`.

---

## 4. mapOp: удаление `if (op === "exec") return "invoke"`

Удаление корректно: `ALL_OPS` теперь не содержит "exec", значит путь
`mapOp("exec")` из `handleSubmit` недостижим через UI. `mapOp("invoke") → "invoke"`
(fallthrough `return op`) — корректно: `"invoke"` уже является каноническим
Operation, дополнительного маппинга не нужно.

**AC-3 пройден** по логике; не пройден по CSS (см. R-1 выше).
